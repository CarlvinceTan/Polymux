# Presentations

Build a coherent visual story, not a document split across slides.

## Workflow

1. Inspect the complete source deck or reference before editing. Preserve its
   master, theme, layout system, proportions, and visual language.
2. Plan the narrative and give each slide one clear purpose.
3. Use an installed presentation library or office conversion tool. Check the
   environment first and do not silently substitute an unavailable runtime.
4. Prefer native text, shapes, tables, and charts so the result remains
   editable. Keep typography, margins, alignment, and color consistent.
5. Save a new deck unless the user explicitly requests an in-place edit.
6. Render every slide, inspect each at full size, then check the deck as a
   sequence. Fix overflow, tiny text, broken charts, overlaps, inconsistent
   footers, and unresolved placeholders.
7. Reopen the final PPTX and verify the slide count before reporting success.

For a question about an existing deck, inspect the relevant full slide and do
not modify the file.
