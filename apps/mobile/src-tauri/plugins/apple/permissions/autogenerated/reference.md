## Default Permission

Native Apple sign-in and device-only account storage

#### This default permission set includes the following:

- `allow-signIn`
- `allow-secureGet`
- `allow-secureSet`
- `allow-secureRemove`
- `allow-updateAutoFill`
- `allow-disableAutoFill`
- `allow-registerPush`
- `allow-oauth`
