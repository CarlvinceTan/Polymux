# Devices

Polymux can use another paired computer as a Host for Assistant work. The conversation stays in the Desktop you are using while commands, files, and connected tools run on the selected device.

## Pair a device

Open **Devices** from the footer of the chat drawer. You can connect with a QR code, a one-time code, or the direct connection option. When both computers are signed in to the same account, they can find each other automatically; signing in is otherwise optional.

The other device must have Polymux installed. The Devices panel links to current installers and provides a command for setting up a Host on a supported computer.

## Choose where work runs

Choose a device before starting a conversation. The Assistant device picker appears when a connected Host is available, and the selected computer remains responsible for that conversation's runs.

An offline Host stays in the device list but cannot start new work. Choose another connected device or use the current computer instead.

## Manage connections

The Devices panel shows each configured Host and whether it is online or offline. Removing a remote device from the current Desktop clears its connection. Connected-device access is tied to the paired identity, so pairing one computer does not grant access to every device on an account.

For the data involved in remote work, see [Privacy and permissions](/docs/privacy-and-permissions/).
