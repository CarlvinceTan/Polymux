## Features

### Desktop

- Rename Locker to Vault and keep existing local vaults through a one-time migration.
- Unlock Vault with Touch ID on supported Macs.
- Manage Vault groups, pinned items, trash, sync settings, and encrypted account backups in one workspace.
- Give each Team bot its own agent runtime, model, and reasoning settings.
- Let teammates create durable peer bots and retire their schedules when the owner is archived or removed.
- Choose allow, ask, or off device access for every configured Host, with per-device overrides.
- Open app settings beside the app so its tab, scroll position, and unfinished work stay in place.
- Search Settings and app configuration from one place.

### Usage

- Show local agent history beside Polymux usage, with separate All usage, Polymux, Assistant, and Team views.
- Scan supported local agent sessions without sending prompts or tool arguments to the renderer.
- Show scan status, local-agent count, refresh state, and when totals include estimates.

### Calendar

- Suggest calendar events found in chats and keep dismissed suggestions dismissed.
- Lay out overlapping and nested timed events without losing their order.
- Manage connected calendar accounts from Calendar settings.

### Browser

- Suggest visited pages and searches while typing an address.
- Fill passwords, authenticator codes, and passkeys from Vault through the extension.

### CLI

- Browse workspaces, devices, bots, schedules, tasks, Usage, and Vault from the terminal interface.
- Select a paired Host directly, preserve workspace state, and follow runs through their terminal result.

### Mobile

- Use the renamed Vault on-device and through a paired Host or account.

### Hub

- Configure Hub behavior without leaving the workspace and keep the connected account platform visible.

## Bug Fixes

### Desktop

- Preserve existing vault data and settings when upgrading from the Locker name.
- Recheck device policy before a queued Host request is delivered or resolved.
- Retire a bot's schedules when that bot is removed or its spawned peer is archived.
- Preserve unsaved editor text and browser address drafts while opening app settings.

### CLI

- Keep bot creation, deletion, device approval, and schedule editing scoped to the selected Host.

## Improvements

### Desktop

- Keep the Team conversation readable while agent activity, bot setup, and group creation change state.
- Keep the Connections directory focused on skills, MCP servers, plugins, and bots.
- Use isolated parser workers and private caches for local usage scans.

### CLI

- Expand workspace navigation and keep long content safe in narrow terminals.
